Jury Lab

Synthetic simulation for argument stress-testing only; not empirical jury research.
Published studies found that LLM jurors diverge from human jurors (Sun et al., Law & Human Behavior, 2025), so treat these verdicts as a way to test an argument, not as a forecast.

How this was run
All people, companies and documents here are fictional. Every count, tally and delta is computed by code from the jurors' structured votes; the model only writes each juror's vote and words.
