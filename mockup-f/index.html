How I work

Rules I bring to every project

  1. Write the system before the thing. A story bible before the novel, a 16-section prompt before the screenplay, a walkthrough of how the work is really done before the app. The system is what makes the result repeatable.
  2. The model drafts, code decides. In business software the AI reads and suggests, while prices, totals and matching are computed in code, and a person approves every change.
  3. Ship the whole arc. A product is not done at the demo. Tests, a walkthrough, a pilot pack, and notes for the next AI session all ship with it.
